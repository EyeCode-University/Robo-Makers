## Суть задания

Создай систему **открытия сундуков** как в Clash Royale используя только **HTML, CSS и JavaScript** (без React/Vue/Angular). При клике на сундук он открывается с анимацией, и выпадают случайные карты с разной редкостью.

---

## Типы сундуков

| Сундук | Что выпадает |
|--------|--------------|
| 🪙 **Деревянный** | 3-5 карт, больше обычных |
| 🥈 **Серебряный** | 5-8 карт, есть редкие |
| 🥇 **Золотой** | 8-12 карт, много редких |
| 💎 **Легендарный** | 10-15 карт, гарантированная легендарка |

---

## 📋 Что должно быть

### 1️⃣ Главный экран

```
┌─────────────────────────────────┐
│                                 │
│         [Деревянный]            │
│         [Серебряный]            │
│         [Золотой]               │
│         [Легендарный]           │
│                                 │
└─────────────────────────────────┘
```

Пользователь выбирает тип сундука → переход к анимации открытия

---

### 2️⃣ Анимация открытия

**Этапы:**
1. Сундук трясётся (shake animation)
2. Крышка открывается (rotate + opacity)
3. Появляются карты по одной (fade in + scale)
4. Подсветка редких карт (glow effect)

---
