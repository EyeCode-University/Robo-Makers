<h1>📝 Тема: Создание кастомного музыкального плеера (HTML, CSS, JavaScript)</h1>

Example: ⚠️ Использовать готовые библиотеки, UI-компоненты или копировать готовые решения запрещено.
Весь интерфейс и логика должны быть написаны самостоятельно.

Главная цель задания — научиться:

работать с тегом <audio>

управлять воспроизведением через JavaScript

создавать интерактивный интерфейс

управлять состоянием плеера

Функционал плеера

Плеер должен поддерживать следующие возможности:

▶️ Play / Pause
Кнопка запуска и остановки музыки.

⏭ Следующий трек
Переключение на следующий трек из списка.

⏮ Предыдущий трек
Переключение на предыдущий трек.

🔀 случайное воспроизведение (shuffle)

📊 Полоса прогресса (Progress Bar)
Пользователь должен видеть прогресс воспроизведения.

Также пользователь должен иметь возможность кликнуть по полосе прогресса, чтобы перемотать трек.


🔊 Контроль громкости
Добавить ползунок для регулировки громкости.
