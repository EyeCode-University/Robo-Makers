<h1>📝 Тема: Игровой генератор образов с динамической сменой атмосферы (HTML, CSS, JavaScript)</h1>

Example: ⚠️ Использовать готовые UI-библиотеки, CSS-фреймворки, готовые dress-up игры и конструкторы аватаров запрещено.

Весь интерфейс и логика должны быть написаны самостоятельно.

Главная цель задания — научиться:

работать с DOM и управлять состоянием интерфейса через JavaScript

реализовывать слайдер выбора вариантов (одежда / образы)

динамически менять фон и атмосферу страницы (цвета, градиенты, изображения)

создавать простой игровой интерфейс с отзывчивой анимацией (игровой UI)

<h2>🎮 Общая идея</h2>

Создайте интерактивный экран персонажа в стиле мини-игры: в центре — силуэт/персонаж, вокруг — элементы интерфейса для смены одежды и атмосферы.
По нажатию на элементы слайдера студент должен видеть, как одновременно меняется и одежда персонажа, и фон/атмосфера всего экрана (цвет, градиент или фоновые картинки в стиле разных миров: киберпанк, неон, спортзал, зима и т.д.).

<h2>🎯 Обязательный функционал</h2>

👕 Слайдер стилей одежды

Реализуйте слайдер (стрелки «влево/вправо» или точки/буллеты) для переключения вариантов одежды персонажа.

Каждый вариант должен визуально отличаться (цвет, форма, аксессуары).

Переключение происходит по клику, без перезагрузки страницы.

🌌 Синхронная смена атмосферы

При смене одежды должен автоматически меняться фон страницы или большая фоновая область (контейнер сцены).

Атмосфера может быть реализована как:

разные фоновые изображения (город ночью, неоновый киберпанк, зимний лес, спортзал и т.п.),

или разные цветовые схемы/градиенты (темный фиолетовый, кислотный неон, пастель и т.д.).

Ощущение: выбрал «боевой» костюм — фон стал более агрессивным и контрастным; выбрал «зимний» — фон холодный и снежный.

🕹 Игровой визуальный стиль

Интерфейс должен выглядеть как часть игры:

кнопки с hover-эффектами,

лёгкие анимации (transition/transform),

чёткая зона персонажа и зона управления.

Добавьте заголовок/логотип мини-игры (например, «OUTFIT ARENA» или «STYLE QUEST»).

📜 Отображение текущего стиля

Отображайте текстово текущий выбранный образ:

Название стиля (например, «Неоновый рейвер», «Зимний самурай», «Уличный кодер»).

Краткое описание атмосферы (1–2 предложения).

Информация должна обновляться при переключении слайдера.

<h2>🧠 Структура данных</h2>

<h2>⚙️ Рекомендуемая структура проекта</h2>

<code>index.html</code> — разметка персонажа, слайдера, текста описания, кнопок управления

<code>styles.css</code> — оформление персонажа, игрового UI, анимаций, фоновых состояний

<code>script.js</code> — логика слайдера, переключение образов, управление состоянием и DOM

Минимальный набор элементов на странице:

контейнер сцены (фон, в котором всё происходит)

блок персонажа (силуэт, поверх которого меняется одежда)

элементы управления (стрелки слайдера, индикаторы текущего образа)

текстовая панель с названием и описанием текущего стиля

<h2>💡 Идеи для игровых деталей</h2>

Добавьте «рандомайзер» образа: кнопка, которая выбирает случайный стиль.

Звуковой эффект при смене стиля (короткий FX в игровом стиле).
